## 停止理由

実証には外部通信を遮断した状態で localhost の人工 HTTP receiver に接続する必要がある。既存の offline sandbox 用 Firewall 規則は、外部通信と localhost の TCP 全ポートを遮断する構成だった。公式 source では offline sandbox SID に適用される規則であり、通常のユーザープロセス全体の通信遮断を示すものではない。許可された proxy port は空で、現在のプロセスは管理者ではない。

この構成から検証 receiver を許可するには sandbox の provision 設定と Firewall 規則の変更が関係する。既存 OS 設定の変更は実証用一時領域の承認に含まれていない。HTTP proxy 環境変数だけでは外部遮断の根拠にできないため、隔離成立前の CLI 起動を止めた。

これは構成確認による停止判断であり、通信遮断の実測結果でも、他の隔離方法すべてが不可能という結論でもない。
